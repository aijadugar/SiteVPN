# SiteVPN

SiteVPN is a modern, privacy-focused VPN and identity protection platform designed to make secure browsing simple, fast, and accessible. Powered by a modular architecture and developer-friendly ecosystem, SiteVPN provides high-speed VPN connectivity along with advanced privacy tools like temporary emails, SMS numbers, and secure identities.

---

## 🔒 Why SiteVPN?

SiteVPN delivers a next-generation privacy experience built on these core principles:

- **Speed & Reliability** — globally distributed VPN nodes ensure low latency and stable connectivity.
- **Privacy First** — strict no-logs policy and encrypted communication.
- **Modern Stack** — Next.js, modular APIs, microservices, and scalable VPN infrastructure.
- **User-Friendly Design** — one-tap connect, clean dashboard, connection stats.
- **Complete Privacy Suite** — temp emails, SMS forwarding, private identities, and more.
- **Developer-Friendly** — easy to extend, integrate, and self-host.

---

## 🚀 Features

- 🔐 **High-speed VPN connection**
- 🆕 **Temporary emails & inbox viewer**
- 📱 **SMS forwarding / virtual phone numbers**
- 🌍 **Multiple global VPN nodes**
- 📊 **Real-time connection stats**
- 🌑 **Dark & light mode support**
- 🧩 **Modular, production-ready components**
- ⚙️ **API-first architecture**

---

## 📦 Tech Stack

- **Frontend:** Next.js, React, TailwindCSS, shadcn/ui  
- **Backend:** Microservices (Node / Go / Python depending on service)  
- **Infrastructure:** High-availability VPN servers, secure tunnels  
- **Tools:** TypeScript, Docker, Prisma, Cloudflare, etc.
